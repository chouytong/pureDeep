# E4 masked-domain adaptation smoke and numerical consistency

The first E4 smoke run stopped before adaptation because exact `2e-5` comparison to the original Phase-3B frozen feature cache failed (subject-level maximum absolute difference about 0.0028). No formal E4 run had started. The Phase-3B extraction used global 64-window batches, while E4 must use only the target split's allowed raw subjects. A direct comparison of 5,740 inner-train windows with the archived Phase-3C layer4 cache found maximum absolute difference 0.002111, mean absolute difference 5.14e-7 and p99 absolute difference 0: rare floating convolution batch effects, rather than a systematic raw-window or subject mapping mismatch.

The isolated E4 smoke check was made quantitative: subject-level final1024 features must have max absolute difference <0.005, mean absolute difference <1e-5 and p99 absolute difference <1e-4 before adaptation. The accepted smoke values were max 0.001776, mean 4.56e-7 and p99 0. The raw preprocessing and mapping were unchanged. CUDA deterministic algorithms and `CUBLAS_WORKSPACE_CONFIG=:4096:8` are fixed for formal runs. One masked-adaptation batch smoke and one downstream WSSL-STR training batch passed; train-only raw subjects, zero validation windows in adaptation, unchanged BN running statistics, updated layer5 parameters, checkpoint reload and no outer loader were verified. No validation metric was used to change this tolerance or any model choice.
