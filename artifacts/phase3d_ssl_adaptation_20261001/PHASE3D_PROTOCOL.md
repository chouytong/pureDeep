## E1 — bottleneck adapter, single configuration

Frozen pretrained HarNet10 final 1024D wrist features are passed through `1024→64→GELU→1024` with a residual addition to the original feature. The adapter's second linear layer is zero-initialized so the initial feature equals the Phase-3B cache. HarNet backbone remains frozen. Train only this adapter as the *new encoder-side adaptation*; original STR, Phase-3B LayerNorm(1024)+Linear(1024,64) SSL projection and downstream path train with the original recipe. Adapter uses the same base LR 2e-4 and weight decay 1e-4 as the projection, without a new optimizer group or tuning. The adapter is before the existing frozen-feature projection; bilateral fusion, activity aggregation and structured residual are untouched. Run 45 matched inner units after smoke, exact initialization-logit/checkpoint reload and frozen-cache-gradient checks. Compare adapter against frozen Phase-3B and read-only Phase-3C last-block adaptation. Do not vary dimension if the gate fails.

## E2 — one gated SSL-STR fusion, independent of E1

Keep the same frozen HarNet feature and existing 64D SSL projection. At each activity/wrist, compute a 64D gate from `[STR wrist64, projected SSL64]` through `Linear(128,32)→GELU→Linear(32,64)→sigmoid`, then `fused_wrist = STR wrist + gate * projected SSL`. Initialize the final gate bias to logit(0.9) and final gate weights to zero; the SSL projection stays zero-initialized, so initial logits exactly equal original STR. This is the only gated architecture; no attention or gate-width search. Train from scratch with the fixed WSSL recipe on all 45 units. Compare directly with frozen Phase-3B. If E2 fails the retention gate, E3 is not run.

## E3 — conditional activity-conditioned lightweight gate

Only if E2 passes its frozen-WSSL retention gate, add one learned scalar logit bias per each of the 11 fixed activities to the E2 gate before sigmoid (11 extra trainable parameters, shared across wrists and 64 features). All else stays E2-identical. Train 45 matched units. Retain E3 only if it passes the common gate against frozen WSSL and the BA/AUROC paired gate against E2, without worsening recall or seed SD versus E2. Do not search individual activities or alternative gate forms. If E2 fails, record E3 as pre-registered conditional not run, not as a negative measured result.

## E4 — conditional PADS-domain masked SSL adaptation

If E1/E2/E3 yield no retained configuration, the remaining frozen-transfer adaptation question is tested once by train-subject-only self-supervised adaptation. For each target split/seed, read raw Acc XYZ windows only for that split's inner-training and validation subjects using the Phase-3B fixed 48-sample trim, ±3g clip, 100→30 Hz anti-alias resampling, first/last 10 s or edge padding. The validation raw windows are used solely after adaptation for feature inference, never for adaptation, checkpoint choice, loss, normalization or mask statistics. No outer subject file may be opened for that target split.

Initialize the official pretrained HarNet10. Freeze layers1–4; update only layer5 at LR 1e-5, with BN running statistics fixed. A temporary reconstruction decoder `Linear(1024,900)` at LR 1e-3 predicts the 3×300 input window. Per window, mask 15% of time positions in contiguous 15-sample blocks across all 3 axes, replacing them with zero. Optimize masked-position MSE for exactly 5 epochs, batch 64, AdamW weight decay 1e-4. The decoder is discarded. No class labels, supervised head, validation early stopping or checkpoint selection is allowed in this adaptation. Extract final1024 features for the target inner-train and validation subjects from unmasked windows; average windows exactly as Phase-3B and train the unchanged WSSL-STR classifier with the original supervised recipe and fixed 0.5 threshold. This tests domain SSL adaptation, not a new classification head. Run one smoke/fold with subject access audit and logits/shape checks before 45 formal matched units. Compare to frozen Phase-3B with the common retention gate. If E1 or E2/E3 already passes, E4 is not run and is recorded as conditional not executed.

## Final decision

If no new candidate passes, retain frozen Phase-3B WSSL-STR and stop this Phase-3D search. If one passes, choose the passing candidate with the highest 15-split paired BA gain, then AUROC; do not combine candidate mechanisms without a new separately planned study.
