# 采样率与时间戳

FACT：所有时间轴严格递增、无重复时间戳；元数据标称100Hz。median-dt推得fs范围99.206547–100.807653Hz，首末时间跨度推得平均fs范围98.731899–100.795455Hz。两者不能混称同一个采样率。

EVIDENCE：4腕记录含dt>10×本记录median的大间隙，最大0.646577s。这是时间戳间隙，不证明一定丢包；round(dt/median)−1只是缺失网格点proxy，也可能受系统clock/采集延迟影响。当前STR丢弃时间列后按100Hz索引序列处理，因此这些间隙在模型输入时间轴被压缩；影响多少判别信息未知。其余小抖动也不能自动称采样故障。

STR未进行显式传感器重采样；HarNet将固定1000点按3/10重采样至300点，标称30Hz，由预训练输入约束决定。实测时基不完全100时，目标实际物理频率也仅近似30。内置FIR抗混叠存在，不能建议“补上缺失抗混叠”。不按症状/标签修正时间戳；先查clock语义与设备记录，再决定是否适合规则化，不能在大间隙上直接平滑插值。
