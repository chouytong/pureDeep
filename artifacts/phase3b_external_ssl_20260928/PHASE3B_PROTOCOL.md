# PURE-DEEP PHASE-3B DEVELOPMENT: frozen transfer protocol

Date 2026-09-28. This study uses fixed 15 inner-development subject splits, seeds 42/43/44, train-only STR normalization, frozen original STR-01 architecture/recipe, PD=0/DD=1, eleven ordered activities and left/right wrist order. No FOE-01 outer result or prediction, H1, handcrafted statistical feature, teacher/distillation/fusion, model shopping, threshold tuning, or new aggregation/attention/gating/ranking loss/augmentation is allowed. Phase-1/2/3A formal artifacts are read-only. New outputs live only here.

## External encoder identity and preprocessing

The sole selected external model is official OxWearables `ssl-wearables` HarNet10, pinned Git commit `150550ea5d41800229c95e36f88f5bf0d2e7cf04`; checkpoint `model_check_point/mtl_best.mdl`, SHA-256 `c64f9135d99e2dcdfc9ae7cc0672f2bcc438df9ceb8215665882f92cddd162a6`, 42,014,098 bytes. The hub loader reports 131 transferred extractor weights; all 131 `feature_extractor` state keys match with no missing key. Its classifier is randomly initialized and unused. Official input is Acc XYZ, 10 s × 30 Hz = [N,3,300], in g with ±3g clipping; no per-window z-score is used. Frozen feature extraction uses the eval-mode output of `feature_extractor`, shape [N,1024,1] → 1024D. License is the official academic-use license. Official sources: https://github.com/OxWearables/ssl-wearables/blob/main/README.md ; https://github.com/OxWearables/ssl-wearables/blob/main/hubconf.py ; https://github.com/OxWearables/ssl-wearables/blob/main/data_parsing/README.md .

PADS raw observation metadata documents 100 Hz Acc XYZ in g and Gyro in rad/s. The existing STR six-channel input remains the separately processed `raw Acc − L1 trend` plus Gyro, with original train-only normalization. The SSL branch uses corresponding raw PADS Acc XYZ after the same fixed first-48-sample trim that defines the valid STR sequence, never STR-normalized Acc or Gyro. Clip raw Acc to [−3,+3] g, then anti-alias resample each channel from 100 to 30 Hz using fixed polyphase ratio 3/10. For each activity/wrist, a 2000-sample valid sequence yields the first and last 1000-sample 10 s windows, and their two frozen 1024D embeddings are averaged. A 976-sample valid sequence is deterministically edge-padded by 12 samples at each end to 1000, yielding one window. This rule is label-independent and frozen before validation. It maintains subject → 11 activities → left/right wrist. No window, crop, amplitude, normalization or threshold is chosen using validation.

A single fixed random-frozen control uses exactly the HarNet10 `feature_extractor` architecture initialized with random seed 20260928 and kept in eval mode. Both encoders receive exactly the same raw-window tensors and deterministic aggregation. All raw-to-embedding computation is label-independent; projection/classifier training is split-specific, on inner-train subjects only. Subject IDs connect the cached embedding to each split; arrays are never matched by row position alone. Frozen caches are not fitted on PADS labels and are never updated with validation gradients.

## Frozen transfer candidates

A: SSL-only pretrained HarNet10 embeddings → shared LayerNorm(1024)+Linear(1024,64) per wrist → fixed bilateral [left,right,mean,absolute difference,2 masks] 258D → shared Linear(258,16)+ReLU per activity → ordered 11×16=176D flatten → Linear(176,2) subject logits. All activity/wrist masks are honored. Only projection and subject classifier train with the original split-specific balanced CE and STR optimizer/scheduler/early stopping. This is a feasibility check, not a replacement for STR.

B: STR + pretrained-frozen HarNet10. Keep original STR wrist encoder on processed Acc+Gyro. Map each frozen SSL wrist embedding through LayerNorm(1024)+Linear(1024,64), zero-initialized Linear, and add it residually to the corresponding 64D STR wrist representation. Recompute the existing bilateral fusion from those wrist vectors; the existing activity attention aggregation, structured residual and final classifier stay unchanged. All STR and projection parameters train with the original balanced CE/recipe. The external encoder remains frozen and is never part of the optimizer. Final prediction uses original STR final logits only.

C: STR + random-frozen HarNet10, identical to B except frozen random encoder weights. Projection, residual insertion, training recipe, seeds, and split data are identical. A fixed random control is sufficient for this one-model feasibility test; no random-initialization shopping.

Before full runs: verify raw units and path mapping, input/feature dimensions, checkpoint/feature hashes, all masks and subject IDs, frozen-encoder gradient absence, original STR logits equivalence at zero-initialized residual, smoke checkpoint reload, train-only normalization, and no outer loader. Then run A/B/C for 15 splits × 3 seeds. Do not launch full fine-tuning.

## Statistics and decision

Three seed metrics are averaged inside each split; 15 fixed splits are primary paired units. Report six metrics, BA/AUROC/DD Recall seed SD, prediction score correlation and threshold disagreement across seeds, positive-split counts, paired differences, 10,000 split-bootstrap 95% CI, paired Cohen dz and BA/AUROC BH-FDR. Do not treat 45 runs, subject pairs or windows as independent. Also average the three DD probabilities by subject ID before recomputing six ensemble metrics for each candidate. Phase-3A STR ensemble AUROC 0.7586 is an inference reference only; it does not enter training or threshold choice.

B is retained only if it exceeds STR baseline and C on BA and AUROC with positive paired means, ≥10/15 positive splits for each, bootstrap 95% CI lower bounds >0 on both primary metrics; Macro-F1 and DD Recall do not decline in mean, PD Recall does not fall by >0.01, and BA/AUROC seed SD does not exceed 1.25× STR baseline. A positive SSL-only result without B gain indicates transfer/fusion compatibility limits, not permission to search new fusion. If pretrained and random control are close, stop this encoder. Only retained frozen transfer justifies a separate Phase-3C minimal adaptation protocol; otherwise no partial or full fine-tuning and no automatic second-model search.
